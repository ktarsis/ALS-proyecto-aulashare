Descripcion breve:
Aplicacion web colaborativa para compartir recursos universitarios por asignatura. Los usuarios registrados pueden crear asignaturas, publicar recursos mediante URL, comentarlos y valorarlos.

Comandos de ejecucion:
1) python -m venv .venv
2) source .venv/bin/activate
3) pip install -r requirements.txt
4) redis-server &
5) flask --app run.py run --debug
